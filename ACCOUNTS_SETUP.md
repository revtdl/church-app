## 4️⃣ GET FIREBASE KEYS (3 minutes)

**Go to:** https://firebase.google.com/console

**If you don't have a Firebase project:**
1. Click "Create Project"
2. Name: `ChurchNexus`
3. Click "Create"
4. Wait for creation

**Get your API Keys:**
1. Go to ⚙️ **Settings** (top-left)
2. Click **"Project Settings"**
3. Click **"General"** tab
4. Scroll down to "Your apps"
5. Find "Web" app section
6. Copy these 6 values:

```
REACT_APP_FIREBASE_API_KEY = ____________________
REACT_APP_FIREBASE_AUTH_DOMAIN = ____________________
REACT_APP_FIREBASE_PROJECT_ID = ____________________
REACT_APP_FIREBASE_STORAGE_BUCKET = ____________________
REACT_APP_FIREBASE_MESSAGING_SENDER_ID = ____________________
REACT_APP_FIREBASE_APP_ID = ____________________
```

**Save these somewhere safe!** (You'll need them during deployment)
